# 轨道靶车蓝牙串口测试上位机

此版本用于完成：上位机操作 → 蓝牙虚拟串口 → STM32协议解析 → 电机模式控制 → 实时状态回传。

## 启动

```powershell
npm install
npm start
```

串口固定为 `115200 / 8-N-1`。连接成功后程序会发送 PING、遥控模式和零摇杆值，随后每 200 ms 发送心跳。

## 协议

```text
AA 55 | VER | CMD | SEQ | LEN | PAYLOAD | CRC16_L CRC16_H
```

- `VER` 固定为 `0x01`。
- `LEN` 最大 40。
- CRC16/MODBUS 从 `VER` 计算到最后一个 payload 字节。
- 所有 16/32 位数采用小端序。

| CMD | 方向 | 说明 |
|---|---|---|
| `0x01` | 上→下 | PING |
| `0x02` | 上→下 | 心跳 |
| `0x10` | 上→下 | 设置模式，payload 1字节 |
| `0x11` | 上→下 | 遥控量，move/rotate 各 int16 |
| `0x12` | 上→下 | 急停 |
| `0x13` | 上→下 | 解除急停 |
| `0x14` | 上→下 | 设置自动速度，M3508/GM6020各uint16 |
| `0x15` | 上→下 | 设置遥控双轴映射，M3508/GM6020满幅转速各uint16（4字节）；旧版2字节平移设置仍兼容 |
| `0x80` | 下→上 | ACK |
| `0x81` | 下→上 | PONG |
| `0x82` | 下→上 | STM32测试变量状态 |

模式值：`0=停止、1=遥控、2=自动旋转、3=自动平移、4=自动组合`。

- 遥控：M3508平移满幅默认 `1500 rpm`、可设 `200～2000 rpm`，死区后线性映射；GM6020旋转满幅默认 `200 rpm`、可设 `20～400 rpm`，死区后按平方曲线映射。
- 自动旋转：GM6020按设定速度持续旋转，默认 `200 rpm`，安全范围 `50～400 rpm`，M3508停止。
- 自动平移：M3508按设定速度往返运行，默认 `1500 rpm`，安全范围 `200～2000 rpm`，由左右ES3144霍尔端点触发换向，GM6020停止。
- 自动组合：自动平移和自动旋转同时执行。
- 模式切换先停200 ms；急停、蓝牙断联或对应CAN电机离线都会禁止输出。
- 自动速度设置默认折叠并锁定；仅停止/遥控模式、两个电机CAN反馈在线，且M3508实际转速不超过50 rpm、GM6020不超过20 rpm时允许解锁。
- 解锁15秒后自动重锁，应用成功后立即重锁并折叠；下位机执行相同的模式、在线和实际转速检查。
- 遥控双轴映射使用同一折叠区内的两个滑条和解锁/应用按钮；仅在固件状态帧同时上报两个映射值、摇杆归中、模式与电机状态安全时可修改。发送后等待 `0x15` 的ACK，未确认不显示成功。状态帧新增字节37～38报告GM6020映射值，总长度为39字节。
- 实时状态帧字节8～9、14～15分别为M3508、GM6020的CAN反馈电流值（带符号、经过现有滤波，非安培单位），不再是PID输出。字节20～21为标记`43 49`；若收到未带标记的旧固件状态帧，上位机显示`--`，不会把旧PID值误显示为电流。

两个ES3144霍尔模块使用低电平触发，程序每5 ms采样一次，连续3次（约15 ms）确认触发或释放。任一端触发时自动平移向另一端换向；两端同时触发时停止平移并报告端点异常。
