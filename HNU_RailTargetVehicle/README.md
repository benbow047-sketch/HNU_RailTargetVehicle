# HNU 轨道靶车控制工程

本工程基于 STM32F407 + FreeRTOS，已整合蓝牙串口控制、M3508平移、GM6020旋转以及两个ES3144数字霍尔端点模块。

## 当前硬件配置

| 功能 | 引脚/接口 |
|---|---|
| 蓝牙串口TX/RX | USART1：PA9 / PB7，115200 8-N-1 |
| 电机总线 | CAN1：PD1 / PD0，1 Mbps |
| 左侧霍尔数字输出DO | PB12，低电平触发、内部上拉 |
| 右侧霍尔数字输出DO | PB14，低电平触发、内部上拉 |
| 指示灯 | PH10 |

两个霍尔模块均使用5 V供电并与STM32共地。PF0/PF1、PB13/PB15不再参与端点检测。

## 电机配置

- M3508：CAN1，ID2，反馈ID 0x202，遥控满幅默认1500 rpm（200～2000 rpm可设）。
- GM6020：CAN1，ID4，反馈ID 0x208，遥控满幅默认200 rpm（20～400 rpm可设）。
- 遥控摇杆回中时目标转速立即置0，使用独立制动PID主动刹车；M3508实际转速进入±30 rpm后释放制动电流。急停或蓝牙掉线仍直接输出0电流。
- 遥控平移在死区后线性映射到M3508满幅值，旋转在死区后按平方曲线映射到GM6020满幅值。命令`0x15`携带两个小端uint16（平移、旋转各2字节）同时设置；旧版2字节平移设置仍兼容。仅停止/遥控模式、无急停且相关电机在线并接近停止时接受设置。39字节状态帧的字节35～38回传两个映射值。
- 39字节状态帧的字节8～9、14～15现为M3508/GM6020的CAN反馈电流值（带符号、经过现有滤波，非安培单位），不再回传PID输出；字节20～21填入`43 49`作为格式标记，方便上位机区分旧固件。

## 端点逻辑

- 霍尔DO连续3次采样为低电平（约15 ms）：端点触发。
- 霍尔DO连续3次采样为高电平（约15 ms）：端点解除。
- 自动平移到端点后立即清零M3508控制，停200 ms，再反向运行。
- 两端同时触发、蓝牙断联、急停或M3508 CAN离线时，自动平移停止。

默认约定M3508正转让车向右移动。如果实车方向相反，将 `USER/modules/TargetMotor/target_motor.c` 中的 `TRACK_POSITIVE_DIRECTION_IS_RIGHT` 改为0。

## 构建输出

使用ARM GCC/Ninja构建目录：

```text
cmake-build-debug/HNU_RailTargetVehicle.hex
cmake-build-debug/HNU_RailTargetVehicle.bin
```

第一次测试应先断开电机动力，只连接两个霍尔模块，用磁铁分别确认左右原始输入及端点状态，再进行电机测试。
